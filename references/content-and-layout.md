# 新论文的内容与视觉默认

## 证据先于排版

记录论文题录、版本日期、PDF页码、图表和公式编号。重点核查最终发表版与预印本差异；不要携带上一篇论文的DOI、超参数、对照方法或结论。模板只提供视觉框架，不携带其作者、正文、日期、数据或图片。

综述材料适合解释背景，不能把它的全部参考文献当作已逐篇核验的来源。发现公式与文字冲突时并列原式、疑点和建议实现；不能擅自把建议修正写成作者原式。

表内比较限定在作者收录的方法与协议；不冒称统一重跑。推导的百分比写出原始值、计算口径，并标“据原表计算”。误差棒没有明确统计定义时不要写成95%置信区间。案例图与整体统计的证据强度分别表述。

## 常见叙事，不是固定页码

- 背景：题录、应用任务、输入输出、已有方法与瓶颈。
- 方法：总体架构、关键模块、公式及训练/推理职责。
- 证据：数据与协议、指标、主对比、消融、代表案例。
- 讨论：已有证据支持什么、尚缺什么、本组可借鉴的可检验建议。

一般20页文献分享适合约20—30分钟，但以用户实际时间、听众与材料决定。不将单篇精读自动扩成系统综述，也不把本机独立实验混入作者结果。

## 本 Skill 的可替换视觉默认

画布1280×720；深蓝 `#1356A2`，白底，浅蓝 `#F0F6FB`，红色 `#C32626`；微软雅黑为主，公式用Cambria Math。顶栏约31—32 SVG px，正文21—24 px，脚注约12 px；实际PowerPoint字号随插入比例换算，不能把像素数直接当pt。

顶栏标题 + 一句核心判断 + 主证据/解释区 + 简短结论 + 来源。优先采用图文双栏、参数三栏、原始数据对照表、通栏大图等布局；按图像比例分配空间，不机械堆卡片。原图包含很多面板时减少周围文字，保留整图并提供高清查看途径。

红色用于关键差异、参数、数值或解释边界，避免全段红字。文字过少时补必要的实验条件、变量含义与读图要点；不能靠额外无依据结论填空。

## 轻度PowerPoint微调

已确认HTML视觉优先。960×540 pt蓝白模板中，本次验证可用的微调是标题24 pt、来源9—9.5 pt、页码11 pt并保持右边界；这不是其他模板的强制尺寸。先核对剩余空间，再调整。主正文与公式不需要为“看起来做过优化”而任意缩放。

汇报人、组别和日期未知就留待填写。不要从用户账户名或文件作者猜测汇报人。
